# Sales Analytics Project

## 📊 Project Overview

This project analyzes sales data using Java, Oracle SQL, CSV, and Power BI.

The project focuses on understanding sales performance, profit, product performance, category performance, and regional sales.

## 🛠️ Tools & Technologies

- Java
- Oracle SQL
- Power BI
- Excel / CSV
- GitHub

- Electronics generated the highest sales with ₹198,500.

## 🎯 Project Objective

The objective of this project is to demonstrate an end-to-end sales analytics workflow using data preparation, Java programming, SQL analysis, and Power BI visualization.
